# Selection Guide（范本选择指南）

改写或新增注释前，按本页决策树选择范本。全流程用大模型阅读判断，不需要脚本。

## 决策树 A（对每个已存在的逻辑注释单元）

1. **位于 vendor/、第三方、生成目录？** → 跳过，永不触碰。
2. **命中 INDEX 承重清单，或语言范本文件的"承重清单"？** → 原样保留。疑似失效的抑制指令（如 `# noqa` 对应的警告已消失）→ escalate，不自动删。
3. **同一声明/语句上存在互相矛盾的注释？** → 按 `rewrite-recipes.md` R10 以代码实际行为为准合并为一个规范块；无法从代码判定谁对 → escalate。
4. **纯流程残留？**（步骤旁白、agent 叙事、里程碑标签、复述代码的字面解释、日志/署名/日期注释、注释掉的代码、教程式冗长说明）
   → remove。例外：若该声明是公开 API 且缺少文档注释 → 不直接删了事，转为决策树 B 的补写流程。
5. **耐久知识与过程元数据混合？** → 按 `rewrite-recipes.md` 整块改写，套用模板。
6. **已是耐久知识、无过程元数据？** → 不是 finding，保持原样（收敛规则）。"我可以说得更精炼"不构成改写理由。
7. **无法判定？** → escalate。

## 决策树 B（对没有注释、候选补写的位置）

补写以"必要"为准，不设数量上限；但每一条新增注释都必须能通过事实审查（见 `rewrite-recipes.md` 自检）。默认立场：**缺注释本身不是 finding**，只有命中下列触发条件才是。

1. **位于 vendor/、第三方、生成目录？** → 永不补写。
2. **命中任一必要性触发？**
   - 公开/导出 API 缺少文档注释（库代码默认要求；应用/脚本代码跟随仓库惯例，不主动补写）；
   - 非显然约束/不变量/哨兵值无解释（如 `-1 means unknown`）；
   - 活跃 workaround 无注释（必须带 issue/ticket 链接与解除条件）；
   - 抑制指令缺 reason 且该语言支持 reason（见 R8）；
   - 公开弃用无弃用标记。
   → 记 `add` finding，按语言范本选定模板，整块写入（cite 模板编号）。
3. **未命中触发？** → 不是 finding。签名自解释的参数、私有实现细节、"将来可能有用"的推测，都不构成补写理由。
4. **命中触发但事实填不满模板槽位？** → escalate，不臆造。

## 按场景选模板

| 场景 | 适用模板 | 说明 |
|---|---|---|
| 公开/导出 API 的文档注释 | 语言文件"文档注释范本" | 库代码默认要求；应用/脚本代码跟随仓库惯例，不主动补写 |
| 函数定义处的实现解释 | 语言文件"行内注释-why 范本" | 解释 why，不复述 what |
| 非显然约束/不变量/哨兵值 | 行内注释-why（约束型） | 如 `-1 means unknown` |
| workaround / 上游缺陷 | 行内注释-why（workaround 型，带链接） | 必须保留 issue/ticket 链接与解除条件 |
| TODO/FIXME | 语言文件"任务标记"节 | 保留可执行项并规范化格式 |
| 弃用 | 弃用模板（有属性用属性：`#[deprecated]`、`@Deprecated`、`@deprecated`） | 注释弃用仅在无属性机制时用 |
| 文件头 | 语言文件"文件头"节 | 许可证部分无条件保留 |
| 抑制指令 | 语言文件"抑制指令清单" | 支持带 reason 的语言必须补 reason |

## 风格决策

- **注释语言**：跟随仓库现有注释语言。仓库无一致语言时，遵循官方指引（PEP 8：用英语，除非 120% 确定所有读者共享你的母语）。
- **行宽/折行**：跟随仓库 formatter 配置（black/ruff、prettier、gofmt、rustfmt、clang-format）；模板行宽超限时按 formatter 规则折行，不改结构。
- **同文件一致性**：同一文件已有同种注释时，沿用其既有风格而非本库默认；**新写的注释同样沿用该文件既有风格**（收敛规则的一部分）。
- **注释掉的代码**：一律删除，VCS 承载历史。例外：疑似被外部工具读取、或属于未完成的临时调试现场 → escalate。
- **公开性判断**：拿不准符号是否算"公开 API"时，按仓库目录语义（如 `include/`、`public/`、`pkg/`、导出关键字）判断；仍拿不准 → escalate，不强行补文档。
